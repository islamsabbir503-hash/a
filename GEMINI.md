SILENT CRYPTOGRAPHIC & PROTOCOL ENGINES (100% REAL IMPLEMENTATION)

                                                                                                                                                                                                                                                                                                                                                                                                                                                                 ### 6.1 Silent Pure-JS X25519 WireGuard Keypair Generator (`utils/crypto.ts`)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                 - Implement a 100% self-contained, zero-dependency RFC 7748 Curve25519 (`X25519`) keypair generator in TypeScript using `crypto.getRandomValues(new Uint8Array(32))`:
                                                                                                                                                                                                                                                                                                                                                                                                                                                                   - Clamp the 32-byte private scalar:
                                                                                                                                                                                                                                                                                                                                                                                                                                                                       ```ts
                                                                                                                                                                                                                                                                                                                                                                                                                                                                           priv[0] &= 248;
                                                                                                                                                                                                                                                                                                                                                                                                                                                                               priv[31] &= 127;
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   priv[31] |= 64;
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       ```
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         - Compute the 32-byte public key via Montgomery curve `2^255 - 19` ladder scalar multiplication (`basePoint = [9, 0, ...]`) in `BigInt` or 16-limb `Float64Array`/`Int32Array` field arithmetic (`gf`).
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           - Encode both 32-byte arrays to standard 44-character Base64 strings (`privateKey` and `publicKey`).
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           - When connecting in `⚡ Cloudflare Turbo` mode:
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             - Check if a valid profile exists in `localStorage.getItem('nitrowarp_warp_profile_v1')`. If not (or on fresh registration), generate a fresh X25519 keypair and send `POST https://nitrowarpvpn.sabbirboos0.workers.dev/api/warp-generate` with `{ "publicKey": generatedPublicKey }`.
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               - Inject the client `privateKey` into `<YOUR_PRIVATE_KEY>` inside `wireguardConfigText` and store the complete profile silently in `localStorage` to power the `⚡ Cloudflare Turbo` session.

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               ### 6.2 Silent Base64 `.ovpn` Decoder & Extractor (`utils/crypto.ts`)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               - For every server fetched from `GET https://nitrowarpvpn.sabbirboos0.workers.dev/api/servers`:
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 - Clean whitespace and decode `server.ovpnConfigBase64` via `atob()`.
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   - Extract:
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       - `protocol`: match `/^proto\s+(udp|tcp)/im` ➔ uppercase `'UDP'` or `'TCP'`.
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           - `port`: match `/^remote\s+([^\s\r\n]+)\s+(\d+)/im` ➔ integer port (e.g., `443`, `1194`).
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               - `cipher`: match `/^cipher\s+([^\s\r\n]+)/im` ➔ string (e.g., `'AES-128-CBC'`).
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 - Attach these decoded properties (`protocol`, `port`, `cipher`) directly to each parsed server object in memory so the UI badges and native OpenVPN tunnel engine have instant access without ever exposing raw config text to the user.
